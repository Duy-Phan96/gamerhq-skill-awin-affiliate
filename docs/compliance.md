# Affiliate disclosure and compliance

This document describes product defaults, not legal advice.

## Default disclosure

Every Awin Discord post generated by this Skill includes a visible disclosure:

```text
Werbung · Affiliate-Link
```

The default supporting sentence is:

```text
Mit Nutzung des Links unterstützt ihr den Server.
```

The supporting sentence does not replace the disclosure.

## Posting behavior

The Skill renders:

- advertiser/offer context;
- the Creative image;
- an HTTPS `View offer` button;
- the visible affiliate disclosure;
- optional administrator-provided title/text.

Post Now requires preview/confirmation.

Recurring campaigns use the same rendering path.

## Administrator responsibility

Administrators remain responsible for:

- complying with the applicable Awin programme terms;
- using only Creatives they are allowed to promote;
- selecting appropriate destination channels/audiences;
- meeting local advertising/disclosure requirements;
- avoiding misleading custom copy.

## Creative state

Automatic posting only uses Creatives that are both:

- user-enabled; and
- in an eligible ACTIVE/NEW state.

MISSING/disabled Creatives are excluded.

## Data minimization

The Skill does not need to store end-user click behavior, purchases or personal Discord message content for its current V1 functionality.
